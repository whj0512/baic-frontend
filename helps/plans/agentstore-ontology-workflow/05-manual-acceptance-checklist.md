# AgentStore 本体建模工作流人工验收清单

## 1. 使用规则

- 本文件是本改造唯一验收清单，不配套任何自动构建、测试、Lint、类型检查、浏览器自动化或 Smoke 脚本。
- 所有项目由用户在真实页面、真实项目和真实 QwenPaw 环境中手工执行并填写。
- 实施 Agent 只能指出本阶段需要执行的编号，不得代填“通过”、实际结果或备注。
- 每完成一个实施阶段，先执行 README 中映射的项目；用户明确确认后才进入下一阶段。
- 最后一项未人工确认前，不得宣布整体改造验收完成。
- 如果某项因外部服务不可用无法执行，在“实际结果”中写明阻塞原因，不得标记为通过。
