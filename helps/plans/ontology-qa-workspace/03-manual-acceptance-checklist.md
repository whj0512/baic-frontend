# `ontology_qa` 工作区人工验收清单

## 1. 使用规则

- 本文件是本改造唯一验收清单，不配套自动构建、测试、Lint、类型检查、浏览器自动化或 Smoke 脚本。
- 所有项目由用户在真实项目、真实 QwenPaw 和真实 GraphDB 环境中手工执行并填写。
- 实施 Agent 只能指出本阶段需要执行的编号，不得代填“通过”、实际结果或备注。
- 阶段一完成后先验证 A、B 组；用户明确确认后才实施阶段二。
- 阶段二完成后验证 C、D 组；最后一项未确认前不得宣布整体完成。
- 外部服务不可用时，在“实际结果”中记录阻塞原因，不得标记通过。
