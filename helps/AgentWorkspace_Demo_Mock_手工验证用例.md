# Agent Workspace Demo Mock 手工验证用例

## 验证说明

- Demo 启动命令：`npm run dev:demo`
- Demo Webview 构建命令：`npm run build:webview:demo`
- Demo Extension 构建命令：`npm run build:demo-extension`
- 本次实现未代替验证人执行以上命令、浏览器操作、Lint 或 TypeScript 检查。
- Demo 模式仍使用现有 BAIC 项目接口；选择项目后才会进入 Agent Workspace。
- QwenPaw 的 Agent、会话、历史、附件和对话流均由浏览器内存中的 Demo transport 提供。
- 最终本体实例关系图仍实时请求项目需求 API 和 GraphDB，该步骤不属于离线 Mock。
- `tqqRiu` 必须按右侧流程面板顺序操作；固定回复游标不会根据用户文字改变分支。
- 页面刷新会清空 Demo 会话；“新建对话”会从当前 Agent 的第一步重新开始。
